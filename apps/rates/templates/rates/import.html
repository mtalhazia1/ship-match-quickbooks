Columns

Column names are not case sensitive. Required columns are marked.

ColumnWhat to put in it
vendor requiredThe vendor's name as it appears on its invoices.
quote_referenceThe vendor's quote or contract number.
originPort of loading, as a name (Ningbo) or UN/LOCODE (CNNGB). Empty means any.
destinationPort of discharge. Empty means any.
equipment{% for code, name in equipment %}{{ code }}{% if not forloop.last %}, {% endif %}{% endfor %}. Empty means any. 40HQ and 20DV are understood too.
valid_from requiredFirst day the rates apply, as 2026-01-31 (31 Jan 2026 and 01/31/2026 work too).
valid_toLast day. Empty means no end date.
currency requiredThree-letter code, e.g. USD.
all_inyes if the ocean freight rate includes surcharges the quote doesn't list.
charge_code requiredA code from the list on the right, or a common name such as THC or BAF.
charge_descriptionHow the vendor writes the charge (optional).
amount requiredThe rate, e.g. 2400.00.
basis requiredcontainer, shipment, bl, kg, cbm, day or hour.
notesAnything to remember about the quote.
Rows with the same vendor, quote reference, lane, equipment and start date make one quote. If that quote already exists, its charge lines are replaced by the ones in the file; otherwise a new quote is added. Every change is recorded in the audit log.
