How events are sent

Each event is a POST with a JSON body: id, type, created, organization and data.object, a summary with references, status, amounts and a link. Never document text or files.

Headers ShipMatch-Timestamp and ShipMatch-Signature (v1= HMAC-SHA256 of timestamp.body with the endpoint's secret) prove it came from ShipMatch.

Answer with HTTP 2xx within {{ timeout|floatformat:0 }} seconds. Anything else is retried with growing pauses, up to {{ max_attempts }} attempts. After {{ disable_after }} failures in a row the endpoint is turned off and admins get an email.

The same event can arrive twice (retries, replays): use its id to skip repeats. The README has a verification example.
